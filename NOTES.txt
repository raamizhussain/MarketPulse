regime_detector.py
- Hidden Markov Model (HMM) : specialized sequential ML model, using time-series dataset, and determines the unobservable, Regime of the market 
- It analyzes Log Returns and Realized Velocity from data to classify market regimes into Stable (State 0) or High-Volatility (State 1) environments

Bug:

Fix: To fix the convergence trap, train the HMM solely on raw Log Returns to eliminate volatility lag, then enforce an explicit sort matrix to drop remaining NaN groups

- It failed to converge bcuz a lack of data variety caused the optimization algorithm to stall and collapse all variance into State 0
- Expectation-Maximization algorithm

- To force convergence and prevent state collapse, we will use Explicit Matrix Initialization by pre-calculating a baseline threshold to feed hard-coded starting parameters directly to the HIMM algorithm
